প্রতিদিনের প্রজেক্ট ম্যানেজমেন্ট এবং কোডিংয়ে সবচেয়ে বেশি ব্যবহৃত প্রয়োজনীয় Git কমান্ডগুলো নিচে ক্যাটাগরি অনুযায়ী সাজিয়ে দেওয়া হলো:

---

**১. প্রজেক্ট সেটআপ ও রিপোজিটরি কনফিগারেশন**

* `git init`
* **কাজ:** বর্তমান ফোল্ডারটিকে একটি নতুন Git রিপোজিটরি হিসেবে ইনিশিয়ালাইজ (শুরু) করে।


* `git clone <URL>`
* **কাজ:** GitHub বা রিমোট সার্ভার থেকে কোনো বিদ্যমান প্রজেক্ট পুরো হিস্ট্রি সহ লোকাল কম্পিউটারে নামিয়ে আনে।


* `git remote -v`
* **কাজ:** লোকাল প্রজেক্টটি কোন অনলাইন/রিমোট রিপোজিটরির (Origin) সাথে যুক্ত আছে তা যাচাই করে।



---

**২. দৈনন্দিন কাজের সাইকেল (Save & Commit)**

* `git status`
* **কাজ:** কোন কোন ফাইলে পরিবর্তন হয়েছে, কোনগুলো Staging Area-তে আছে বা আনট্র্যাকড অবস্থায় আছে তা দেখায়।


* `git add .`
* **কাজ:** বর্তমান ফোল্ডারের সব পরিবর্তিত ও নতুন ফাইলকে পরবর্তী কমিটের জন্য Staging Area-তে যুক্ত করে।
* নির্দিষ্ট ফাইলের জন্য: `git add filename.ext`


* `git commit -m "আপনার মেসেজ"`
* **কাজ:** Staging Area-তে থাকা পরিবর্তনগুলোর একটি স্ন্যাপশট বা ভার্সন সেভ করে।


* `git diff`
* **কাজ:** ফাইলে ঠিক কোন কোন লাইন যোগ বা বিয়োগ করা হয়েছে তা বিস্তারিত দেখায় (কমিট করার আগে)।



---

**৩. রিমোট সিঙ্ক (Push, Pull & Fetch)**

* `git push origin <branch-name>`
* **কাজ:** লোকাল কমিটগুলো GitHub বা রিমোট রিপোজিটরিতে আপলোড করে। প্রথমবার পুশ করতে `-u` ফ্ল্যাগ ব্যবহার করা হয় (`git push -u origin main`)।


* `git pull origin <branch-name>`
* **কাজ:** রিমোট রিপোজিটরি থেকে সর্বশেষ কোড নামিয়ে স্বয়ংক্রিয়ভাবে লোকাল ব্রাঞ্চের সাথে মার্জ (Merge) করে।


* `git fetch`
* **কাজ:** রিমোটের নতুন আপডেটগুলো ডাউনলোড করে কিন্তু লোকাল কোডের সাথে সরাসরি মার্জ করে না (শুধুমাত্র ট্র্যাকিংয়ের জন্য)।



---

**৪. ব্রাঞ্চিং ও মার্জিং (Branch Management)**

* `git branch`
* **কাজ:** লোকাল রিপোজিটরিতে থাকা সমস্ত ব্রাঞ্চের তালিকা দেখায় এবং বর্তমানে কোনটিতে আছেন তা চিহ্নিত করে।


* `git checkout -b <new-branch>` অথবা `git switch -c <new-branch>`
* **কাজ:** নতুন একটি ব্রাঞ্চ তৈরি করে সাথে সাথেই সেই ব্রাঞ্চে সুইচ করে।


* `git checkout <branch-name>` অথবা `git switch <branch-name>`
* **কাজ:** একটি নির্দিষ্ট ব্রাঞ্চ থেকে অন্য ব্রাঞ্চে পরিবর্তন করে।


* `git merge <branch-name>`
* **কাজ:** অন্য কোনো ব্রাঞ্চের করা কোড পরিবর্তন বর্তমান সক্রিয় ব্রাঞ্চের সাথে একত্রিত (Merge) করে।



---

**৫. ভুল সংশোধন ও হিস্ট্রি দেখা (Undo & History)**

* `git log --oneline`
* **কাজ:** পূর্বের সমস্ত কমিট হিস্ট্রি এক লাইনে সংক্ষেপে দেখায়।


* `git restore <filename>`
* **কাজ:** ফাইলে করা সাম্প্রতিক আনকমিটেড পরিবর্তনগুলো বাতিল করে ফাইলকে আগের অবস্থায় ফিরিয়ে নেয়।


* `git stash`
* **কাজ:** বর্তমান অসম্পূর্ণ কাজগুলো কমিট না করে সাময়িকভাবে একটি গোপন স্থানে সেভ করে কোড ক্লিন রাখে।


* `git stash pop`
* **কাজ:** `git stash`-এ জমিয়ে রাখা কাজগুলো আবার ফিরিয়ে আনে।

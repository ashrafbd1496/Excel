# Git Cheat Sheet: প্রয়োজনীয় কমান্ড ও গাইডলাইন

প্রতিদিনের প্রজেক্ট ম্যানেজমেন্ট এবং কোডিংয়ে সবচেয়ে বেশি ব্যবহৃত প্রয়োজনীয় Git কমান্ডগুলো নিচে ক্যাটাগরি অনুযায়ী সাজিয়ে দেওয়া হলো:

---

## ১. প্রজেক্ট সেটআপ ও রিপোজিটরি কনফিগারেশন

* `git init` — বর্তমান ফোল্ডারটিকে একটি নতুন Git রিপোজিটরি হিসেবে ইনিশিয়ালাইজ (শুরু) করে।
* `git clone <URL>` — GitHub বা রিমোট সার্ভার থেকে কোনো বিদ্যমান প্রজেক্ট পুরো হিস্ট্রি সহ লোকাল কম্পিউটারে ক্লোন করে।
* `git remote -v` — লোকাল প্রজেক্টটি কোন অনলাইন/রিমোট রিপোজিটরির (`origin`) সাথে যুক্ত আছে তা যাচাই করে।

---

## ২. দৈনন্দিন কাজের সাইকেল (Save & Commit)

* `git status` — কোন কোন ফাইলে পরিবর্তন হয়েছে, কোনগুলো Staging Area-তে আছে বা আনট্র্যাকড অবস্থায় আছে তা দেখায়।
* `git add .` — বর্তমান ফোল্ডারের সব পরিবর্তিত ও নতুন ফাইলকে Staging Area-তে যুক্ত করে।
  * নির্দিষ্ট ফাইলের জন্য: `git add <filename>`
* `git commit -m "আপনার মেসেজ"` — Staging Area-তে থাকা পরিবর্তনগুলোর একটি স্ন্যাপশট বা ভার্সন সেভ করে।
* `git diff` — কমিট করার আগে ফাইলে ঠিক কোন কোন লাইন যোগ বা বিয়োগ করা হয়েছে তা বিস্তারিত দেখায়।

---

## ৩. রিমোট সিঙ্ক (Push, Pull & Fetch)

* `git push origin <branch-name>` — লোকাল কমিটগুলো রিমোট রিপোজিটরিতে আপলোড করে।
  * প্রথমবার পুশ করতে: `git push -u origin main`
* `git pull origin <branch-name>` — রিমোট থেকে সর্বশেষ কোড নামিয়ে স্বয়ংক্রিয়ভাবে বর্তমান লোকাল ব্রাঞ্চের সাথে মার্জ (Merge) করে।
* `git fetch` — রিমোটের নতুন আপডেটগুলো ডাউনলোড করে কিন্তু লোকাল কোডের সাথে সরাসরি মার্জ করে না (শুধুমাত্র ট্র্যাকিংয়ের জন্য)।

---

## ৪. ব্রাঞ্চিং ও মার্জিং (Branch Management)

* `git branch` — সমস্ত লোকাল ব্রাঞ্চের তালিকা দেখায় এবং সক্রিয় ব্রাঞ্চটি চিহ্নিত করে।
* `git switch -c <new-branch>` — নতুন একটি ব্রাঞ্চ তৈরি করে সাথে সাথেই সেই ব্রাঞ্চে সুইচ করে।
  * বিকল্প কমান্ড: `git checkout -b <new-branch>`
* `git switch <branch-name>` — এক ব্রাঞ্চ থেকে অন্য ব্রাঞ্চে পরিবর্তন করে।
  * বিকল্প কমান্ড: `git checkout <branch-name>`
* `git merge <branch-name>` — অন্য কোনো ব্রাঞ্চের করা পরিবর্তন বর্তমান সক্রিয় ব্রাঞ্চের সাথে একত্রিত করে।

---

## ৫. ভুল সংশোধন ও হিস্ট্রি দেখা (Undo & History)

* `git log --oneline` — পূর্বের সমস্ত কমিট হিস্ট্রি এক লাইনে সংক্ষেপে দেখায়।
* `git restore <filename>` — ফাইলে করা সাম্প্রতিক আনকমিটেড পরিবর্তনগুলো বাতিল করে ফাইলকে আগের অবস্থায় ফিরিয়ে নেয়।
* `git stash` — বর্তমান অসম্পূর্ণ কাজগুলো সাময়িকভাবে একটি ড্রয়ারে সেভ করে ওয়ার্কিং ডিরেক্টরি ক্লিন রাখে।
* `git stash pop` — স্ট্যাশে জমিয়ে রাখা কাজগুলো আবার ফিরিয়ে আনে।

---

# Git Stash: বিস্তারিত গাইড ও বাস্তব উদাহরণ

Git Stash হলো Git-এর একটি সাময়িক ড্রয়ার বা ক্লিপবোর্ডের মতো।

আপনি যখন কোনো ফিচারে কাজ করছেন কিন্তু কাজটি এখনো পুরোপুরি শেষ হয়নি (কমিট করার উপযোগী নয়), ঠিক তখনই জরুরি প্রয়োজনে অন্য ব্রাঞ্চে যেতে হলে বা মেইন ব্রাঞ্চ থেকে নতুন আপডেট পুল করতে হলে `git stash` ব্যবহার করা হয়। এটি আপনার অসম্পূর্ণ পরিবর্তনগুলোকে নিরাপদে লুকিয়ে রেখে ওয়ার্কিং ডিরেক্টরি একদম ক্লিন করে দেয়।

### বাস্তব পরিস্থিতির উদাহরণ

> পরিস্থিতি: ধরুন, আপনি `feature-login` ব্রাঞ্চে লগইন বাটন ডিজাইন করছেন। অর্ধেক কাজ হয়েছে, এমন সময় `main` ব্রাঞ্চে একটি জরুরি বাগ ফিক্স করার প্রয়োজন পড়ল। 
> 
> আপনি অসম্পূর্ণ ভাঙা কোড কমিট করতে চান না, আবার ফেলে দিতেও চান না। সমাধান: Git Stash।

#### ধাপ ১: অসম্পূর্ণ কাজ সাময়িক সেভ করে রাখা
লগইন বাটনের কাজটিকে একটি ডেসক্রিপশন সহ স্ট্যাশে লুকিয়ে ফেলুন:

git stash save "wip: login button half done"

# অথবা নতুন তৈরি ফাইল সহ স্ট্যাশ করতে:
    git stash -u

    (নোট: -u বা --include-untracked ফ্ল্যাগ দিলে আনট্র্যাকড বা নতুন তৈরি ফাইলগুলোও স্ট্যাশে জমা হয়।)

### ধাপ ২: জরুরি বাগ ফিক্স করা
    ওয়ার্কিং ডিরেক্টরি ক্লিন হওয়ায় সহজে মেইন ব্রাঞ্চে গিয়ে ফিক্স সম্পন্ন করুন:
        git switch main
    # বাগ ফিক্স কোড লেখার পর...
    git add .
    git commit -m "fix: critical payment bug"
    git push origin main

### ধাপ ৩: পূর্বের ফিচারে ফিরে আসা
    বাগ ফিক্সের কাজ শেষ করে আবার আপনার আগের ব্রাঞ্চে ফিরে যান:
    git switch feature-login


### ধাপ ৪: স্ট্যাশ করা কাজ পুনরায় ফিরিয়ে আনা
    লুকিয়ে রাখা কোড আবার ওয়ার্কিং ডিরেক্টরিতে ফিরিয়ে আনুন এবং স্ট্যাশ তালিকা থেকে মুছে ফেলুন:
    git stash pop

### অন্যান্য কমান্ড			
    git stash	পরিবর্তিত সব ট্র্যাকড ফাইল সাময়িক ড্রয়ারে তুলে রাখে।			
    git stash -u	ট্র্যাকড এবং আনট্র্যাকড (নতুন তৈরি ফাইল) সব একসাথে স্ট্যাশ করে।			
    git stash save "মেসেজ"	মনে রাখার সুবিধার জন্য একটি নির্দিষ্ট মেসেজ দিয়ে স্ট্যাশ করে।			
    git stash list	পূর্বে স্ট্যাশ করা সমস্ত আইটেমের তালিকা (stash@{0}, stash@{1}) দেখায়।			
    git stash pop	সর্বশেষ স্ট্যাশ ফিরিয়ে আনে এবং স্ট্যাশ লিস্ট থেকে সেটি ডিলিট করে।			
    git stash apply	স্ট্যাশ ফিরিয়ে আনে কিন্তু ভবিষ্যতে ব্যবহারের জন্য লিস্টেও রেখে দেয়।			
    git stash apply stash@{1}	তালিকার নির্দিষ্ট কোনো ইনডেক্সের স্ট্যাশ ফিরিয়ে আনে।			
    git stash show -p	স্ট্যাশের ভেতরে কোন কোন ফাইলে কী পরিবর্তন ছিল তার diff দেখায়।			
    git stash drop stash@{0}	নির্দিষ্ট একটি স্ট্যাশ স্থায়ীভাবে ডিলিট করে।			
    git stash clear	স্ট্যাশ হিস্ট্রি থেকে সমস্ত সেভ করা ডেটা মুছে ফেলে।

# এক্সেলের "Go To" (গো টু) অপশন: সম্পূর্ণ বাংলা গাইড

## "Go To" আসলে কী?

Go To হলো Excel-এর একটি শক্তিশালী ফিচার যা দিয়ে আপনি নির্দিষ্ট ধরনের সেল খুঁজে বের করতে এবং একসাথে সিলেক্ট করতে পারেন। এটি মূলত দুটি স্তরে কাজ করে:

1. সাধারণ Go To (Ctrl+G): নির্দিষ্ট সেল রেফারেন্স (যেমন A1, B10) বা নেমড রেঞ্জে যাওয়ার জন্য।

2. Go To Special (Ctrl+G → Special): বিশেষ ধরনের সেল (ফর্মুলা, খালি সেল, কমেন্ট, ভিজিবল সেল ইত্যাদি) একসাথে সিলেক্ট করার জন্য। এটাই আসল শক্তি।

### কীভাবে ওপেন করবেন

| পদ্ধতি | কী-স্ট্রোক |

|--------|-----------|

| কীবোর্ড (মূল) | `Ctrl + G` অথবা `F5` |

| কীবোর্ড (বিকল্প) | `Ctrl + G` চেপে `Alt + S` |

| রিবন থেকে | Home ট্যাব → Find & Select → Go To Special |

> নোট: Go To Special উইন্ডোতে একবার খুললে, অপশন সিলেক্ট করে OK চাপুন। সিলেক্টেড সেলগুলো হাইলাইট হয়ে যাবে।

## Go To Special-এর প্রতিটি অপশন বিস্তারিতভাবে

### ১. Comments (কমেন্টস)

ব্যাখ্যা: যে সব সেলে কমেন্ট বা নোট সংযুক্ত আছে, সেগুলো একসাথে সিলেক্ট করে।

কেন ব্যবহার করবেন: একটি বড় ওয়ার্কবুকে ছড়িয়ে থাকা কমেন্টগুলো একসাথে দেখতে, মুছতে বা রিভিউ করতে।

উদাহরণ: ধরুন আপনার Sales রিপোর্টের ৫০টি সেলের মধ্যে ১০টিতে কমেন্ট আছে। Comments সিলেক্ট করলে সেই ১০টি সেল একসাথে হাইলাইট হবে। আপনি চাইলে সেগুলো একসাথে ডিলিট করতে পারেন।



### ২. Constants (কনস্ট্যান্টস)

ব্যাখ্যা: যে সব সেলে স্থির মান (টেক্সট, সংখ্যা, তারিখ) আছে — কিন্তু কোনো ফর্মুলা নেই — সেগুলো সিলেক্ট করে।

কেন ব্যবহার করবেন: ফর্মুলা আর হার্ডকোড করা ডেটার মধ্যে পার্থক্য বুঝতে। যদি কোনো সেলে ভুলবশত ফর্মুলার জায়গায় স্থির সংখ্যা বসে যায়, তাহলে ধরা পড়বে।

উপ-অপশন: Numbers, Text, Logicals, Errors — এই চারটি চেকবক্স দিয়ে নির্দিষ্ট ধরনের কনস্ট্যান্ট ফিল্টার করা যায়।

উদাহরণ: আপনার Profit Margin কলামে যদি সব ফর্মুলা থাকার কথা, কিন্তু কোনো সেলে ভুলে ১৫% হার্ডকোড করা আছে — Constants → Numbers সিলেক্ট করলে সেই ভুল সেলটি ধরা পড়বে।



### ৩. Formulas (ফর্মুলা)

ব্যাখ্যা: যে সব সেলে ফর্মুলা আছে, সেগুলো একসাথে সিলেক্ট করে।

কেন ব্যবহার করবেন: ফর্মুলা সেলগুলো রঙ দিয়ে চিহ্নিত করা, অডিট করা, বা ভুল ফর্মুলা খুঁজে বের করা।

উপ-অপশন: Formulas-এর নিচেও Numbers, Text, Logicals, Errors চেকবক্স আছে। শুধু Errors সিলেক্ট করলে সব `#REF!`, `#DIV/0!`, `#N/A` ভুল ফর্মুলা একসাথে ধরা পড়ে।

উদাহরণ: আপনার ওয়ার্কবুকে কোথাও `#DIV/0!` error ছড়িয়ে আছে। Formulas → Errors সিলেক্ট করলে সব error সেল একসাথে হাইলাইট হবে, একে একে ঠিক করা সহজ হবে।



### ৪. Blanks (খালি সেল)

ব্যাখ্যা: সিলেক্টেড রেঞ্জের মধ্যে যে সব সেল খালি, সেগুলো সিলেক্ট করে।

কেন ব্যবহার করবেন: খালি সেল খুঁজে বের করা, ফিল আপ করা, বা সতর্কতার সাথে খালি রো ডিলিট করা।

উদাহরণ: ধরুন একটি Sales টেবিলে Region কলামে কিছু সেল খালি (মার্জড সেল এক্সপোর্টের কারণে)। Blanks সিলেক্ট করে `=A2` লিখে `Ctrl+Enter` চাপলে সব খালি সেলে উপরের মান চলে আসবে — তথাকথিত "Fill Down" technique।

> ⚠️ সতর্কতা: Blanks সিলেক্ট করে "Delete Entire Row" করবেন না — এতে আংশিক খালি রো-ও ডিলিট হয়ে যাবে, আপনার গুরুত্বপূর্ণ ডেটা হারাবে।



### ৫. Current Region (কারেন্ট রিজন)

ব্যাখ্যা: সক্রিয় সেলের চারপাশে থাকা পুরো ডেটা ব্লক (খালি সারি/কলাম দিয়ে ঘেরা) সিলেক্ট করে।

কেন ব্যবহার করবেন: একটি টেবিলের পুরো ডেটা এক ক্লিকে সিলেক্ট করতে, যাতে সর্ট, ফিল্টার বা কপি করা সহজ হয়।

শর্টকাট: `Ctrl + A` (যখন সক্রিয় সেল ডেটার ভেতরে)

উদাহরণ: A1 সেলে ক্লিক করে Current Region সিলেক্ট করলে পুরো টেবিল (হেডারসহ) হাইলাইট হবে। এরপর `Ctrl + T` চেপে এক ক্লিকে টেবিল ফরম্যাট করা যাবে।



### ৬. Current Array (কারেন্ট অ্যারে)

ব্যাখ্যা: যদি সক্রিয় সেলটি একটি অ্যারে ফর্মুলার অংশ হয়, তাহলে পুরো অ্যারে রেঞ্জ সিলেক্ট করে।

কেন ব্যবহার করবেন: অ্যারে ফর্মুলা এডিট বা কপি করার আগে পুরো রেঞ্জ সিলেক্ট করতে।

উদাহরণ: `{=A1:A5*B1:B5}` টাইপের একটি অ্যারে ফর্মুলার যেকোনো একট সেলে ক্লিক করে Current Array দিলে পুরো ৫টি সেল একসাথে সিলেক্ট হবে।



### ৭. Objects (অবজেক্টস)

ব্যাখ্যা: শীটে ভাসমান সব গ্রাফিক্যাল অবজেক্ট — চার্ট, বাটন, শেপ, টেক্সট বক্স — একসাথে সিলেক্ট করে।

কেন ব্যবহার করবেন: সব চার্ট/বাটন একসাথে মুছতে, সরাতে বা ফরম্যাট করতে।

শর্টকাট: `Ctrl + G` → `Alt + S` → `B`

উদাহরণ: আপনার ড্যাশবোর্ড শীটে ১৫টি চার্ট ছড়িয়ে আছে। Objects সিলেক্ট করলে সবগুলো একসাথে হাইলাইট হবে। Delete চাপলে সব চার্ট একবারে মুছে যাবে।



### ৮. Row Differences (রো ডিফারেন্স)

ব্যাখ্যা: সিলেক্টেড রেঞ্জের প্রতিটি রো-তে সক্রিয় সেলের সাথে যে সেলগুলো মিলছে না, সেগুলো সিলেক্ট করে।

কেন ব্যবহার করবেন: ডেটা ভ্যালিডেশনে — দুই কলামের ডেটার মধ্যে অসঙ্গতি খুঁজতে।

শর্টকাট: `Ctrl + `

উদাহরণ: Column A-তে Product নাম, Column B-তে একই Product নাম আছে কিনা চেক করতে চান। A2:B10 সিলেক্ট করে Row Differences দিলে যেসব রো-তে B কলামের মান A-র সাথে মিলছে না, সেগুলো হাইলাইট হবে।



### ৯. Column Differences (কলাম ডিফারেন্স)

ব্যাখ্যা: সিলেক্টেড রেঞ্জের প্রতিটি কলামে সক্রিয় সেলের সাথে যে সেলগুলো মিলছে না, সেগুলো সিলেক্ট করে।

কেন ব্যবহার করবেন: একই ধরনের ডেটার দুই কলামের মধ্যে পার্থক্য খুঁজতে।

শর্টকাট: `Ctrl + Shift + |`

উদাহরণ: মাসের শুরুতে ও শেষের স্টক কলাম দুটির মধ্যে কোন আইটেমের স্টক পরিবর্তন হয়েছে তা দেখতে Column Differences ব্যবহার করা যায়।



### ১০. Precedents (প্রিসিডেন্টস)

ব্যাখ্যা: সক্রিয় সেলের ফর্মুলায় যে সেলগুলোকে রেফারেন্স করা হয়েছে, সেগুলো সিলেক্ট করে।

উপ-অপশন:

- Direct only: শুধু সরাসরি রেফারেন্স করা সেল

- All levels: সরাসরি ও পরোক্ষ সব রেফারেন্স

কেন ব্যবহার করবেন: একটি ফর্মুলার পেছনের ডেটা সোর্স ট্রেস করতে।

শর্টকাট: `Ctrl + [` (Direct only)

উদাহরণ: C1 সেলে `=A1+B1` ফর্মুলা আছে। C1 সিলেক্ট করে Precedents দিলে A1 ও B1 হাইলাইট হবে — বোঝা যাবে এই ফর্মুলা কোথা থেকে ডেটা নিচ্ছে।



### ১১. Dependents (ডিপেন্ডেন্টস)

ব্যাখ্যা: যে সেলগুলোর ফর্মুলা সক্রিয় সেলকে রেফারেন্স করে, সেগুলো সিলেক্ট করে।

উপ-অপশন: Direct only / All levels

কেন ব্যবহার করবেন: একটি সেলে পরিবর্তন করলে কোন কোন ফর্মুলা প্রভাবিত হবে তা বুঝতে।

শর্টকাট: `Ctrl + ]` (Direct only)

উদাহরণ: A1 সেলে একটি ইনপুট মান আছে। A1 সিলেক্ট করে Dependents দিলে যেসব ফর্মুলা A1-কে ব্যবহার করছে (যেমন `=A1*2`, `=SUM(A1:A5)`) সেগুলো হাইলাইট হবে।



### ১২. Last Cell (লাস্ট সেল)

ব্যাখ্যা: ওয়ার্কশীটের যে শেষ সেলে ডেটা বা ফরম্যাটিং আছে, সেটি সিলেক্ট করে।

কেন ব্যবহার করবেন: ডেটার আসল শেষ কোথায়, তা জানতে। প্রিন্ট এরিয়া বা ফরম্যাটিং-এর সীমা বুঝতে।

উদাহরণ: যদি কোনো সেলে ভুলে ফরম্যাটিং রয়ে যায় (খালি কিন্তু কালার করা), Last Cell সেই সেল পর্যন্ত দেখাবে। এতে বোঝা যায় ডেটা আসলে কোথায় শেষ।



### ১৩. Visible Cells Only (শুধু দৃশ্যমান সেল)

ব্যাখ্যা: হিডেন বা ফিল্টার করা রো/কলাম বাদ দিয়ে শুধু দৃশ্যমান সেলগুলো সিলেক্ট করে।

কেন ব্যবহার করবেন: ফিল্টার করা ডেটা কপি-পেস্ট করার সময় লুকানো রো যাতে না আসে, সেজন্য। এটি Excel-এর সবচেয়ে বেশি ব্যবহৃত "power user" ট্রিকগুলোর একটি।

শর্টকাট: `Alt + ;`

উদাহরণ: আপনি Sales ডেটা ফিল্টার করে শুধু "North" রিজিয়ন দেখছেন। পুরো রেঞ্জ কপি করে পেস্ট করলে হিডেন "South" ও "East" রো-ও চলে আসবে। Visible Cells Only সিলেক্ট করে কপি করলে শুধু North-এর ডেটাই পেস্ট হবে।



### ১৪. Conditional Formats (কন্ডিশনাল ফরম্যাট)

ব্যাখ্যা: যে সব সেলে কন্ডিশনাল ফরম্যাটিং প্রয়োগ করা আছে, সেগুলো সিলেক্ট করে।

উপ-অপশন: All (সব) / Same (একই রকম)

কেন ব্যবহার করবেন: কোন কোন সেলে কন্ডিশনাল রুল কাজ করছে তা অডিট করতে।

শর্টকাট: `Ctrl + G` → `Alt + S` → `T`

উদাহরণ: আপনার শীটে "লাল রঙ = ১০০-এর নিচে সেলস" রুল আছে। Conditional Formats → All সিলেক্ট করলে সেই রুল প্রয়োগ করা সব সেল হাইলাইট হবে।



### ১৫. Data Validation (ডেটা ভ্যালিডেশন)

ব্যাখ্যা: যে সব সেলে ডেটা ভ্যালিডেশন রুল (ড্রপডাউন, নাম্বার লিমিট) প্রয়োগ করা আছে, সেগুলো সিলেক্ট করে।

উপ-অপশন: All (সব) / Same (একই রকম)

কেন ব্যবহার করবেন: কোন সেলে ড্রপডাউন আছে, কোনটায় নেই — তা যাচাই করতে। নতুন সেলে একই ভ্যালিডেশন কপি করতে।

শর্টকাট: `Ctrl + G` → `Alt + S` → `V`

উদাহরণ: আপনার Status কলামে "Active/Inactive" ড্রপডাউন থাকার কথা। Data Validation → All সিলেক্ট করলে যে সেলগুলোতে ড্রপডাউন আছে সেগুলো হাইলাইট হবে — যে সেলে নেই সেটি বাদ পড়বে, ধরা পড়বে ভুল।



## সংক্ষিপ্ত সারাংশ টেবিল

| অপশন | কী সিলেক্ট করে | শর্টকাট |

|------|--------------|---------|

| Comments | কমেন্টযুক্ত সেল | `Ctrl+Shift+O` |

| Constants | স্থির মানের সেল | — |

| Formulas | ফর্মুলার সেল | — |

| Blanks | খালি সেল | `Ctrl+G, Alt+S+K` |

| Current Region | পুরো ডেটা ব্লক | `Ctrl+A` |

| Current Array | পুরো অ্যারে | `Ctrl+/` |

| Objects | চার্ট/বাটন/শেপ | `Ctrl+G, Alt+S+B` |

| Row Differences | রো-তে ভিন্ন সেল | `Ctrl+` |

| Column Differences | কলামে ভিন্ন সেল | `Ctrl+Shift+|` |

| Precedents | ফর্মুলার সোর্স সেল | `Ctrl+[` |

| Dependents | যারা এই সেল ব্যবহার করে | `Ctrl+]` |

| Last Cell | শেষ ডেটা/ফরম্যাট সেল | — |

| Visible Cells Only | ফিল্টার-হিডেন বাদ | `Alt+;` |

| Conditional Formats | কন্ডিশনাল রুল সেল | `Ctrl+G, Alt+S+T` |

| Data Validation | ভ্যালিডেশন রুল সেল | `Ctrl+G, Alt+S+V` |

## উপসংহার

Excel-এর Go To Special হলো একটি "hidden cleanup toolkit" — যারা এটি জানেন না, তারা হাজার হাজার সেল ম্যানুয়ালি হ্যান্ডেল করে সময় নষ্ট করেন। ফিল্টার করা ডেটা কপি করতে Visible Cells Only, খালি সেল ভরাতে Blanks, ফর্মুলা অডিট করতে Formulas → Errors, আর ড্রপডাউন চেক করতে Data Validation — এই চারটি অপশন-এ সবচেয়ে বেশি কাজে আসে। নিয়মিত ব্যবহার করলে Excel-এর গতি ও নির্ভুলতা বহুগুণ বেড়ে যাবে।
